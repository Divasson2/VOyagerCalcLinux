Contents

    1. Introduction

    VoyagerCalc is a free desktop application, published by The Calculator Store, that puts an HP Voyager calculator on your computer screen. It does not imitate the calculator with its own maths: it emulates the ARM chip inside the HP Collector’s Edition (CE) calculators and runs the firmware file of your own calculator on it. The calculator on screen therefore behaves exactly as that firmware does.

    Version 0.7.4 supports the HP-16C CE (computer scientist / programmer’s calculator) and the HP-15C CE (scientific calculator), and also the HP-12C CE (financial calculator), which this manual mentions only where it behaves differently.

    What you can do with it

    • Use a full-size photographic calculator face with a live display, with the mouse or the computer keyboard.
    • Watch the stack, storage registers, memory, matrices and program live in the Registers & Program panel (register inspector).
    • Edit HP-15C matrices A–E in a spreadsheet-style Matrix Editor, and paste from or copy to Excel, LibreOffice Calc or Google Sheets.
    • Save and open calculator memory files (2048-byte memory images), and keep the calculator’s memory automatically between launches.
    • Import and export HP-15C programs in the .15c format of Torsten Manz’s HP-15C Simulator.
    • Document a program (title, description, label, register and flag notes, per-step comments) and export it as a PDF or as a text listing.
    • Read and write the memory of your real calculator over USB, with an automatic backup and a read-back check.
    No firmware is included. Neither the app nor the source code contains HP firmware. You supply the firmware .bin file of your own calculator (about 112 KB). See chapter 11 for where to get it. Using firmware is at your own responsibility.
    Test release. 0.7.4 is labelled a test release. USB reading and writing with a real calculator works in the author’s tests on Linux and on Windows 11 ARM (with a real HP-15C). The Windows x64 build is untested on real hardware (it passes the test suites and has been run only under emulation / wine). Please report problems on the GitHub project.

    3. Installation

    3.1 Verify the download (SHA256SUMS)

    Each release includes a file SHA256SUMS that lists the SHA-256 checksum of every file. Download it into the same folder as your package and check that the checksums match before installing.

    SystemCommand (run in the download folder)
    Linuxsha256sum -c --ignore-missing SHA256SUMS
    Expected output: VoyagerCalc-0.7.4-linux-x86_64.tar.gz: OK
    macOS (Terminal)shasum -a 256 -c --ignore-missing SHA256SUMS
    or shasum -a 256 VoyagerCalc-0.7.4-macOS.dmg and compare by eye
    Windows (PowerShell)Get-FileHash .\VoyagerCalc-0.7.4-windows-x64-setup.exe -Algorithm SHA256
    then compare the hash (case does not matter) with the line in SHA256SUMS

    The checksums of each release are published in its SHA256SUMS file (see Appendix A). If a checksum does not match, delete the file and download it again.

    3.2 macOS

    1. Download VoyagerCalc-0.7.4-macOS.dmg (or the .zip) from the release page.
    2. Open the .dmg and drag VoyagerCalc into your Applications folder (from the .zip: double-click to unpack, then move the app to Applications).
    3. Start VoyagerCalc from Applications or Launchpad.

    The Mac app is Developer ID signed, notarized and stapled, so Gatekeeper should open it without warnings. It runs in the macOS App Sandbox with access to files you choose, to USB (for the calculator link) and to the folder ~/Documents/VoyagerCalc Backups/.

    3.3 Windows

    Choose the build: arm64 for a Windows-on-ARM computer, x64 for an Intel/AMD PC.

    Option A – installer (easiest)

    1. Double-click VoyagerCalc-0.7.4-windows-x64-setup.exe (or …-arm64-setup.exe).
    2. It installs for your user only and needs no administrator rights. The program goes to %LOCALAPPDATA%\Programs\VoyagerCalc.
    3. The installer adds a Start menu folder VoyagerCalc with VoyagerCalc, VoyagerCalc USB Test and Uninstall VoyagerCalc.

    Option B – portable zip (no installation)

    1. Right-click VoyagerCalc-0.7.4-windows-x64.zip (or …-arm64.zip) and choose Extract All….
    2. Open the extracted folder and double-click VoyagerCalc.exe.

    The Windows programs and installers are code-signed with Azure Artifact Signing. If SmartScreen still shows a warning, see Troubleshooting.

    3.4 Linux

    1. Download the tarball for your computer: VoyagerCalc-0.7.4-linux-x86_64.tar.gz (Intel/AMD) or …-linux-arm64.tar.gz (ARM).
    2. Unpack it (right-click ▸ Extract, or tar xzf VoyagerCalc-0.7.4-linux-*.tar.gz).
    3. In the new folder, run ./install.sh as your normal user (not with sudo; it asks for the password itself when needed).
      • It checks that the package matches your CPU (x86_64 or arm64) and that the program can start on your system.
      • It installs for your user only into ~/.local/opt/VoyagerCalc, adds a command link ~/.local/bin/voyagercalc, an icon and an entry in the applications menu. An older installation is replaced; your firmware and files are kept.
    4. USB password step. To allow USB access to the calculator, the installer adds the udev rule /etc/udev/rules.d/99-voyagercalc.rules. This needs administrator rights once: a password window opens, or it asks in the terminal (your password if you may use sudo, otherwise the root password). If neither works it prints one line to paste into a terminal. The program is installed in every case; USB access can be set up later with Calculator ▸ Real Calculator (USB) ▸ Fix USB Permissions… or sh ~/.local/opt/VoyagerCalc/share/usb-access.sh.
    5. Start VoyagerCalc from the applications menu (search for “VoyagerCalc”), or run ~/.local/opt/VoyagerCalc/bin/voyagercalc.

    Installer problems: run ./install.sh --verbose and attach ~/.local/share/voyagercalc/install.log to an issue. To build from source instead, see docs/BUILD.md in the repository (CMake ≥ 3.21, C11/C++17 compiler, Qt 6.4+).

    4. First launch

    On first start VoyagerCalc shows a welcome screen: “This app runs the firmware of your own CE calculator (12C, 15C or 16C, including multi-model builds)”.

    1. Click Choose Firmware File… and pick the .bin file you flash to the calculator (about 112 KB). You can also drop the file onto the window.
    2. The app shows “Starting the calculator…”, boots the firmware and then shows the calculator face.
    3. The firmware is remembered: next time the calculator starts straight away. To use another firmware later, choose File ▸ Choose Firmware….

    The remembered firmware, the calculator’s saved state and your program notes are stored in:

    Linux~/.local/share/VoyagerCalc
    Windows%LOCALAPPDATA%\VoyagerCalc
    macOSthe app’s Application Support folder (inside its sandbox container)
    Which firmware? A file that is not between 4 KB and 4 MB is rejected with “does not look like a calculator firmware file”. With HP’s original 12C firmware only the keyboard and display work; the inspector, memory files, program documentation, USB memory transfer, the model switch and keeping memory between launches need the CE firmware’s memory layout and are unavailable.

    5. Choosing the HP-16C or the HP-15C

    The model you get is decided by the firmware file: an HP-16C CE firmware starts an HP-16C, an HP-15C CE firmware an HP-15C. Choose the firmware for the calculator you want with File ▸ Choose Firmware… (or drop the .bin on the window). Switching to another firmware first saves the memory of the firmware that is running, so each firmware keeps its own memory.

    Multi-model firmware: the Model menu

    Some firmware builds contain several calculator images (“multi-model builds”). Then the Model menu lists them, for example 12C, 15C, 15C (15.2) and 16C, and you can switch between them.

    • Switching clears the calculator’s memory (programs, registers and settings), as on the calculator. VoyagerCalc asks first and offers to save a backup.
    • 15C (15.2) is the HP-15C’s double-memory mode, which has more registers than the standard 15C mode.
    • With a single-model firmware the menu shows only that model; with HP’s original 12C firmware it says “HP’s original firmware has no model switch”.

    On macOS

    The Mac app’s Calculator menu also has a Keyboard choice (Automatic (from firmware), 16C, 15C, 12C) and a Face choice (Photo or Drawn).

    The calculator’s back (View ▸ Show Calculator Back)

    View ▸ Show Calculator Back (Ctrl+B / ⌘B) opens a separate window with a photograph of the back of the calculator, with its printed reference tables. Resize the window freely; the picture keeps its proportions.

    • Available for the HP-15C and the HP-16C. With the HP-12C the menu item is greyed out.
    • The window follows the model: switch from the 15C to the 16C and it shows the 16C’s back. When you switch to the 12C, the Windows and Linux apps close it; the Mac app shows “The back picture is available for the HP-15C and HP-16C.”

    6. Keyboard and mouse input

    6.1 Mouse

    • Click a key to press it; it stays down while you hold the mouse button.
    • Click f/g Labels (View menu, on by default): clicking the gold label above a key presses f and the key together; clicking the blue label on a key’s front presses g and the key. The label lights up under the pointer. Turn the option off to make every click press the key itself.
    • Hold a key down (latch): right-click a key (or Ctrl-click; on macOS ⌘-click or right-click). Latched keys let you play combinations such as ON + another key one key at a time. Keys ▸ Release Held Keys lets them go.
    • Show Key Help (View menu, off by default): when the pointer rests on a key, a tooltip shows the key’s functions and its keyboard shortcut.
    • Key Click Sound (View menu, off by default): a soft, deep click on each key press.
    • Drag and drop onto the window: a firmware .bin, a memory file (2048 bytes or a .bin15c/.15c-type ending) or a program-notes file (.voyagerdoc).

    6.2 Computer keyboard

    • Tap Shift on its own = f. Tap Alt on its own (Option on a Mac) = g.
    • Alt + key (Option + key on a Mac) = g, then the key (its blue function).
    • Shift still types * + _ % as usual.
    • Each physical key holds its calculator key down while held, so chords work.
    • Esc is the ON key (Calculator ▸ ON / OFF).
    • Keys combined with Ctrl (⌘) go to the menus, not to the calculator. Typing in another window, such as the Matrix Editor, does not reach the calculator.
    • Letters are not case-sensitive.

    7. The register inspector (Registers & Program)

    Open the panel with View ▸ Registers & Program (Ctrl+I / ⌘I). It appears to the right of the calculator and the window grows to make room. It updates live while you use the calculator and while programs run.

    Header

    The top line shows the model (HP-16C, HP-15C or HP-15C (15.2)) with tags such as ext. memory, Complex, PRGM (program mode) or RUNNING. The second line shows the current mode (for example HEX WSIZE 16 2's on the 16C), the set flags (16C flags 4 and 5 are shown as 4(C) and 5(G); 15C flag 8 as 8(C)) and the program position line 012 / 045.

    Views

    Three buttons choose what is shown: Both, Registers or Program. The choice is remembered. The section headers stay pinned at the top while you scroll.

    Stack

    Listed from top to bottom as I, LAST X, T, Z, Y, X (since 0.7.3). On the 12C the section is “Stack and financial registers”. On the 16C, integers carry a base suffix (h, o, b, d) with the decimal value below; long binary numbers are grouped in fours. In complex mode on the 15C, a value is shown as a + bi.

    Memory and matrices (HP-15C)

    • Memory: a bar of the 15C’s memory pool with the g MEM figures, showing how the registers are shared between storage registers, matrices and program.
    • Matrices: matrices A–E with their size (for example 3×3), the number of registers and their location; the RESULT matrix is tagged. Click a matrix to expand its values (up to 6 columns shown; copy as TSV to see all).

    Storage registers

    “Storage registers (n)” lists every register. Tick Non-zero registers only to hide empty ones.

    Program

    “Program (n lines)” lists each step with its line number, key codes and mnemonic. The current line is highlighted and kept in view, also while a program runs.

    Copying and comments

    • Right-click a register: Copy <value>, and on the 16C also Copy decimal <value>, followed by the register commands below.
    • Right-click a matrix: Copy Matrix X as TSV (for a spreadsheet).
    • Double-click a program line (or right-click ▸ Add Comment…/Edit Comment…) to attach a comment to that step. Comments appear in the listing and in the exported documentation, and stay with their step when lines are inserted or deleted. An empty comment removes it.

    GTO from the program listing

    Right-click a program line ▸ GTO nnn (on the 12C GTO nn) moves the program pointer to that line. VoyagerCalc presses the calculator’s own keys: GTO CHS nnn on the 15C, GTO . nnn on the 16C and g GTO nn on the 12C (g GTO . nn in program mode). It works in run mode and in program mode; in program mode the display then shows that line. GTO is never recorded as a program step. It is greyed out while a program runs.

    Register context menu

    Below the Copy items, a right-click on a register offers RCL, STO, STO+ STO− STO× STO÷, RCL+ RCL− RCL× RCL÷ and x≷, each with the register’s real name, for example STO− R5, RCL× R.3 or x≷ I. Each command is carried out by pressing the calculator’s keys exactly as you would (STO+ R5 presses STO + 5; x≷ R5 on the 15C presses f x≷ 5), so the result, the stack lift and LAST X are what the calculator itself does. Commands the model has no instruction for are greyed out:

    CommandHP-15CHP-16CHP-12C
    RCL, STOR0–R9, R.0–R.9 and IR0–RF, R.0–R.F and IR0–R9, R.0–R.9 and n, i, PV, PMT, FV
    STO+ − × ÷yes (registers and I)– (the 16C has no register arithmetic)R0–R4 only
    RCL+ − × ÷yes (registers and I)––

    The commands are greyed out on the X, Y, Z, T and LAST X rows, on registers that the calculator reaches only through (i) (R20 and up on the 15C, R32 and up on the 16C) and while a program runs.

    In program mode (PRGM) a register command is keyed into the program as an instruction, just as if you pressed the keys: STO R2 inserts the step STO 2 after the current line and stores nothing. In run mode the command is executed at once.

    8. HP-15C Matrix Editor

    Open with Calculator ▸ Matrix Editor… (Ctrl+Shift+M / ⇧⌘M). It is available when the calculator runs as an HP-15C (including 15.2 mode).

    1. Choose a matrix (Matrix A–E) and its size (Rows × Columns). A memory bar shows what fits: “r × c = n registers; matrix X can have up to m here”. A size that does not fit is shown in red.
    2. Fill in the spreadsheet-style grid: Tab moves right, Enter moves down. Numbers can be typed as 1,5, 1.5 or 2E-3. Invalid cells are marked red.
    3. Click Apply to put the matrix into the calculator’s memory. It is then ready to compute with on the calculator, is kept across restarts, and can be sent to your real calculator with Real Calculator (USB) ▸ Write to Calculator…. Setting 0 × 0 frees the matrix’s registers.

    Other buttons

    • Reload from Memory (Mac: Open from Memory): shows the selected matrix as it is in memory now.
    • Paste Matrix: copy a range in Excel, LibreOffice Calc or Google Sheets, then paste. The size is set automatically and a preview is shown first (with warnings for ragged rows, cells that are not numbers, or a size that does not fit); Fill the Grid accepts it.
    • Copy as TSV (Mac: Copy): copies the grid tab-separated for a spreadsheet, with the calculator’s own digits. Values survive the round trip exactly.

    9. Saving and loading state

    9.1 Automatic continuous memory

    Like the real calculator, VoyagerCalc keeps its memory: when you quit, the calculator’s state is saved, and the next launch continues where you left off. The state is stored per firmware in the data folder (see chapter 4). Calculator ▸ Reset Calculator (clears memory)… restarts the calculator without the saved memory and also clears the program notes.

    9.2 Memory files

    • File ▸ Save Memory File… (Ctrl+S) saves the whole calculator memory (programs, registers and settings), a 2048-byte image. The default endings are .bin12c, .bin15c and .bin16c, but you can type any ending.
    • File ▸ Open Memory File… (Ctrl+O) loads one. The file is checked by its content, not its ending; the older endings .12c, .15c, .16c and .12cmem still open.
    • Before loading, VoyagerCalc test-loads the memory and asks for confirmation (you can save a backup of the current memory first). If the memory belongs to another model or mode, it says so — for example that it needs the 15C (15.2) double-memory mode, or that it fits another model in the Model menu.
    • HP-16C memory files are checked for their layout before loading: standard memory, extended memory (B7B7 / E8E8) and the early E3E3 layout, which is converted automatically. A file for a different layout gives a warning instead of loading wrong values.

    9.3 Program notes and documentation

    • File ▸ Program Info… (Ctrl+Shift+I): title, author, model, number of steps, a description (a line starting with ## is a heading, - a bullet), and the program’s labels (where defined, where called from), registers and flags, each with a field for your notes. Buttons: Save Notes…, Export PDF…, Done.
    • File ▸ Save Program Notes… / Open Program Notes…: notes are saved as a .voyagerdoc file (JSON, the same format on Mac, Windows and Linux). A notes file saved next to a memory file (for example FinancePac.15c.voyagerdoc) is found automatically when that memory file is opened. Clear Program Notes clears them.
    • File ▸ Export Program Documentation (PDF)… (Ctrl+Shift+E): a PDF with a cover (model, firmware, steps, description), labels, registers and flags, matrices, and the listing (step, display, keys — with key-cap symbols on the 15C — and comments). Paper size: File ▸ PDF Paper Size ▸ A4 / US Letter.
    • File ▸ Export Listing as Text…: the same as a plain-text file.

    9.4 HP-15C program files (.15c)

    • Both items are available only for the HP-15C; on the 12C and 16C they are greyed out (“HP-15C only”).
    • File ▸ Import Program (.15c)… reads a program in the file format of Torsten Manz’s HP-15C Simulator, keys it into the emulated calculator and checks the result. It replaces the program and its notes; registers, matrices and settings are kept. If the program does not fit, memory is left unchanged.
    • File ▸ Export Program (.15c)… writes a file the simulator opens directly.
    • These items are for the HP-15C only; on the 12C and 16C they are disabled.

    9.5 Transferring memory with your real calculator (USB)

    1. Connect the calculator by USB, turn it off, hold f and ENTER, press ON (the display stays blank: USB mode).
    2. Use Calculator ▸ Real Calculator (USB):
      • Read from Calculator – loads the calculator’s memory into the emulator.
      • Write to Calculator… – first backs up the calculator’s current memory to Documents/VoyagerCalc Backups (for example HP-15C calculator 2026-10-16 08.12.33.bin15c), asks for confirmation, writes the emulator’s memory, reads it back and compares. Then press ON on the calculator to leave USB mode and ON again to use it.
      • Save Calculator Memory to File… – saves the calculator’s memory to a file without changing the emulator.
      • Fix USB Permissions… (Linux only) – installs the udev rule if it is missing.
    If the calculator holds a different model’s memory than the emulator runs, writing will most likely make the calculator show Pr Error and clear its memory — VoyagerCalc warns you. A memory that uses the 15C (15.2) double memory needs the calculator to be set to 15C (15.2) mode first (turn it off, hold g and ENTER, press ON, 4, then the key under 15.2), otherwise it shows Error 10.

    In a virtual machine, connect the calculator’s USB device to the guest system (in Parallels: Devices ▸ USB & Bluetooth), not to the host.

    11. Firmware and the real HP-15C CE / HP-16C CE

    The HP Collector’s Edition calculators contain an ARM Cortex-M4 microcontroller. Its firmware imitates HP’s original “Nut” processor, which runs the original calculator program. VoyagerCalc’s emulator core (plain C11, no third-party or HP code) imitates the ARM chip: it executes each instruction of your firmware file as the chip would. As a result:

    • The emulated calculator behaves as the firmware says — functions, display, flags, memory layout, and the extras of extended firmware builds (such as extended memory, menus or a stopwatch where the firmware has them).
    • It runs in real time: auto power-off, the stopwatch and the blinking display behave as on the real calculator, and program speed matches a real 15C CE (the clock-speed settings in the Service menu are scaled the same way).
    • Memory files are the same 2048-byte memory images the real calculator holds, so memory can move between the app and the calculator over USB.

    Program capacity

    How many program steps fit is decided by the firmware and its memory mode, exactly as on the calculator — the app does not add its own limit. Program files exchanged through Import / Export Program (.15c) hold up to 999 steps (steps 001–999, the HP-15C Simulator’s limit). What actually fits the HP-15C depends on its memory: in the standard 15.0 mode at most 448 one-byte steps, in the 15.2 double-memory mode more. VoyagerCalc checks this before and while it keys a program in.

    Where to get firmware

    The Calculator Store keeps pages with firmware downloads and links:

    • Official HP firmware: thecalculatorstore.com/c/resources-and-links/official-hp-calculator-firmware
    • Test and extended firmware (HP-15C CE C8C8, HP-16C CE B7B7, HP-12C CE multi E6E6, …): thecalculatorstore.com/c/resources-and-links/hp-calculator-test-firmware
    • Simulators and emulators: thecalculatorstore.com/c/resources-and-links/simulators-and-emulators

    12. Troubleshooting

    12.1 macOS – Gatekeeper

    The 0.7.4 Mac app is Developer ID signed, notarized and stapled, so macOS should open it normally. If macOS still refuses to open it:

    • Make sure you downloaded it from the official GitHub release and that its checksum matches SHA256SUMS (3.1).
    • Move the app into Applications before opening it.
    • Open System Settings ▸ Privacy & Security and click Open Anyway next to the VoyagerCalc message, or Control-click the app and choose Open.

    12.2 Windows – SmartScreen

    The Windows builds are code-signed (Azure Artifact Signing), so Windows should not show an “unknown publisher” warning. If SmartScreen shows “Windows protected your PC”, click More info, then Run anyway.

    On a Windows-on-ARM computer, use the arm64 build; the x64 build also runs there, but more slowly.

    12.3 Linux – dependencies and installer

    • VoyagerCalc bundles Qt 6.8 and needs a 64-bit Debian 13 / Ubuntu 24.04 or newer. If install.sh says “VoyagerCalc cannot start on this system”, your system is too old (it prints the reason); please tell the author which system you have.
    • “This package is for arm64 computers, and this computer is x86_64” (or the reverse): download the other tarball.
    • “Please run this as your normal user (without sudo)”: run ./install.sh without sudo.
    • “Please unpack the whole .tar.gz first”: extract the complete archive and run the script from inside the extracted folder.
    • If VoyagerCalc does not appear in the menu, start it with ~/.local/opt/VoyagerCalc/bin/voyagercalc. For a detailed log run ./install.sh --verbose and look at ~/.local/share/voyagercalc/install.log.

    12.4 USB connection problems

    • No access (Linux): choose Calculator ▸ Real Calculator (USB) ▸ Fix USB Permissions…. If no password window can open, VoyagerCalc shows one line to paste into a terminal. Then unplug and replug the calculator and put it in USB mode again.
    • Linux self-test: run voyagercalc --usb-selftest in a terminal. It lists USB devices, says whether the calculator is there, whether you may use it and whether another program holds it, and tries the read in several ways (a step that never returns is shown as STUCK).
    • Windows self-test: with the calculator in USB mode, double-click VoyagerCalc USB Test.bat (Start menu or program folder); the result is saved as VoyagerCalc-USB-Test.txt on your Desktop.
    • USB log: Help ▸ Show USB Log shows every USB step, with Copy, Save… and Clear (Linux file: ~/.local/share/VoyagerCalc/usb.log). On the Mac: Calculator ▸ Log USB Traffic and Show USB Log in Finder.
    • Attach the self-test output or log to an issue on GitHub.

    12.5 Other messages

    • “Choose a firmware file first”: no firmware is loaded yet; choose your .bin.
    • Menu items greyed out: many items need a running calculator; Matrix Editor and .15c import/export need the HP-15C; Show Calculator Back needs the HP-15C or HP-16C; in the inspector, register commands the model lacks are greyed out; with HP’s original 12C firmware the inspector, memory files and USB memory transfer are unavailable.
    • A memory file “may not fit”: it is probably for another model or memory mode; follow the suggestion in the message (for example switch to 15C (15.2) in the Model menu).
