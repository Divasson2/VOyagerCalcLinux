# Assets

* `faces/face_{12c,15c,16c}_nolcd.png`: the calculator face pictures drawn behind the live LCD (the LCD glass is emptied; the
  app paints the display over it).
* `geometry.json`: key and LCD rectangles measured on those pictures (input of `tools/gen_face_geometry.py`).
* `fonts/`: documentation-PDF fonts, with their notice.
* `icon/AppIcon-256.png`: application icon.
