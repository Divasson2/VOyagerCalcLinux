# Fonts used for the documentation PDF

Credit: **key-cap font by Eric Rechlin; seven-segment display font by Torsten Manz**
(HP15C Simulator Font © 2005 Torsten Manz, Freeware).

| File | What it is |
|---|---|
| `HP15CSimulatorDisplay.ttf` | Seven-segment LCD font: renamed copy of "HP15C Simulator Font © 2005 Torsten Manz, Freeware" (family renamed to "HP15C Simulator Display"). |
| `HP15CSimulatorKeys.ttf` | Key-cap font by Eric Rechlin (v2.0, Dec 2022; original file `HP_15c_v2.0.ttf`), renamed copy (family "HP15C Simulator Keys"). |

Only the font *name table* was changed (so the two files do not clash, both originals being called "HP15C Simulator
Font"); glyphs and all other metadata, including the copyright fields, are exactly as in the original files.

repository's MIT licence. They are redistributed here with the permission obtained by the VoyagerCalc author. If you are
an author or rights holder and want them removed, please open an issue. The program embeds only subsets of the fonts in
the PDFs it writes. They are loaded from the program's resources by file, never installed on the system.
